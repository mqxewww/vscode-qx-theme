# QX Theme for Code

A calm dark theme for Visual Studio Code, with an Islands-style layout: the
editor sits on a darker background than the surrounding panels, so each area
reads as a separate block.

## Installation

1. Open the Extensions view (`Ctrl+Shift+X`) and search for **QX Theme for
   Code**. It is available on the VS Code Marketplace and on Open VSX (for
   VSCodium, Cursor, etc.).
2. Run **Preferences: Color Theme** (`Ctrl+K Ctrl+T`) and select **QX Theme**.
